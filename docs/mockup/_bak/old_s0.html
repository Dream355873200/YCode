# 钓获手账 · 产品规格书
由左侧配置 + 对话推导 · v3

## 概述
城市用户的水果电商，主打 30 分钟送达。

## 模块
### 账号登录
- 手机号 + 6 位验证码
- Token 走 secure storage
- 失效自动回登录页

### 商品列表
- 瀑布流 · 图片懒加载
- 下拉刷新 / 触底加载
- 卡片：图/名/价/加购

### 购物车
- 本地持久化（游客可用）
- 增减 / 左滑删 / 全选

### Go 后端
- Gin + GORM · SQLite(dev)
- 用户/商品/购物车 REST API
- JWT 鉴权 · 参数化查询

## 非目标
- 订单 / 支付 / 推送
（对话 v2 收敛）

## 验收
- analyze 零 error
- 主流程测试 100% 通过
- 冷启动 < 2s
