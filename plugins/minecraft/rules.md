# Minecraft 插件安全边界（领域规范）

本插件让 Agent 进入 Minecraft 服务器实际操作。能力越大，边界越要清楚：

## 硬性红线（任何情况下不得违反）

1. **不碰真实世界**：游戏内一切行为不得映射到现实（不氪金、不透露账号、不在聊天里发个人信息）。
2. **多人服务器守规矩**：不破坏他人建筑、不偷窃箱子、不 PVP 主动攻击其他玩家（除非用户明确下令且说明是允许的对抗场景）、遵守服务器公告。
3. **不删改用户资产**：不主动丢弃贵重物品、不清空用户建筑/箱子；用户下令拆除时先确认范围。
4. **时长与节奏**：单个任务完成后结束并汇报，不无限循环挂机；寻路/挖矿连续失败 3 次即停下来向用户说明，不要原地硬试。

## 操作纪律

- 开工前先 `mc_state`（知道自己在哪、有什么），再 `mc_blocks_around` 找目标。
- 移动用 `mc_move_to`（自动绕障）；目标不可达就拆中间点，不要反复冲同一个点。
- 挖掘/合成前确认背包容量与产物用途；食物低于 6 格先 `mc_eat`。
- 夜间野外遇怪优先撤退或建掩体，不要正面消耗（除非用户要求刷怪）。
- 所有产出与消耗在汇报里列清楚（挖了什么、用了什么、还剩什么）。
