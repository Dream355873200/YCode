# Stardew 插件安全边界（领域规范）

1. **不碰真实世界**：游戏内行为不映射现实；不透露账号；不在多人服务器聊天里发个人信息。
2. **金钱与资产红线**：不主动卖出「工具/传家宝/任务物品」（Category 非出货类的物品先问用户）；
   大额消费（>500g 的单笔购买）先向用户确认。
3. **不透支体力**：体力低于 20% 必须回家睡觉或吃食物，不要硬干到晕倒（晕倒有金钱惩罚）。
4. **睡觉纪律**：每天 2:00 AM 前必须上床睡觉（过了会减员与随机惩罚）；当日结算前汇报收获。
5. **失败即停**：同一动作（按键/传送/互动）连续 3 次结果无变化就停下来向用户说明，不硬试。
6. **时长限制**：单个游戏日任务完成即汇报，不无限循环挂机。
