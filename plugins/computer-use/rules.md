# 电脑控制纪律

- **开工先加载技能**：第一次使用本插件的任何工具前，必须先调用技能 `computer-use`（Skill 工具）掌握完整的观察-操作循环与错误语义，再开始操作。
- **任务路由（先判类再动手）**：
  - 用户说「打开浏览器」「搜索/搜一下 XX」「看看某网站/某 UP 主的新视频」「帮我上网查 XX」——这类请求**一律走 browser-use 插件**：直接 `browser_navigate` 打开目标网址（例：B 站搜「极客湾」= `https://search.bilibili.com/all?keyword=极客湾`），**禁止**用电脑控制去点桌面浏览器图标再手动输入网址。
  - 只有当目标确实是桌面应用本身（文件管理器、计算器、系统设置、微信/QQ 客户端等非浏览器程序）时，才使用本插件的工具。
- 辅助功能优先：先 `get_app_state` 看语义元素树，按**元素索引**操作；键盘是后备，屏幕坐标是最后手段（只用于 canvas / 自绘界面）。能用元素动作就不要用快捷键。
- 观察一次 → 动作 → 再观察，确认结果真的发生再进行下一步；「API 返回成功」不等于「应用生效了」。元素已消失时必须重新 `get_app_state` 拿新索引，禁止按旧索引盲点。
- 破坏性操作（删除文件、发送消息、下单、关机）执行前必须向用户确认。
- 用户报的应用名要原样使用，不要翻译、简写或去后缀；解析失败就先 `list_apps` 找准确名字。
- 子代理不得使用电脑控制；一次只跑一个自动化会话，冲突时先完成当前任务。
