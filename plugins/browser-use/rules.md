# 浏览器操作纪律

- **开工先加载技能**：第一次使用本插件的任何工具前，必须先调用技能 `browser-use`（Skill 工具）掌握「导航 → 快照 → 动作 → 验证」循环，再开始操作。
- **这类请求归你管，直接出手**：用户说「打开浏览器」「帮我搜/搜一下 XX」「看看某网站/某 UP 主的新视频」「上网查 XX」——不要打开桌面浏览器应用，直接 `browser_navigate` 打开对应网址。常用入口：百度搜索 `https://www.baidu.com/s?wd=关键词`、B 站搜索 `https://search.bilibili.com/all?keyword=关键词`、GitHub `https://github.com/search?q=关键词`。搜到结果后用 `browser_snapshot` 读标题与链接汇报。
- 网页内的一切操作走 browser-use（`mcp__browser__*`），不要用电脑控制去点网页，也不要用 curl 代替需要登录态/JS 渲染的页面检查。
- **快照引用优先**：动作前先 `browser_snapshot` 拿 @eN 引用，按引用点击/输入；只有快照定位不了才用坐标。页面导航或 DOM 变化后引用即失效，必须重新快照——报「不在最近一次快照里」就是提示你重新快照，禁止按旧引用重试。
- **循环**：导航 → 快照 → 动作 → 再快照（或截图）确认结果真的发生，再进行下一步。
- 并行任务各自 `browser_new` 开独立实例，不要抢同一个实例；任务结束 `browser_close` 收尾。右栏浏览器面板对用户可见——你打开的页面用户看得到，不要打开无关页面。
- `browser_evaluate` 是验证性读取与兜底手段：优先快照 + 常规动作，不要用它绕过页面交互去硬改状态。
- 本地开发目标（localhost / 127.0.0.1）同样支持，前端验证（截图 + console + 交互）闭环用它做。
