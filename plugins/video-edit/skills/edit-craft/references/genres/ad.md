# 广告片（15-60s 卖点片）

目标只有一个：让观众记住一件事并产生动作。所有刀为转化服务。

## 档位

- 15s：8-12 刀（快档）；30s：14-20 刀（快-中快）；60s：20-30 刀
- 前 3 秒必须出现「产品最动人的一瞬间」，不是 logo，不是标题

## 结构模板

1. **钩子（0-3s）**：产品最高光的画面/最强反差。1-2 刀，每刀 ≤1.5s
2. **痛点或场景（3-8s）**：观众「这就是我」的瞬间。可用一点慢节奏对比
3. **卖点展示（8-70% 处）**：每个卖点一组镜头（特写+动作+结果），卖点间硬切或 slide
4. **证据（后 1/3）**：数字、对比、使用者反应——可信度镜头，节奏稍缓
5. **收尾（最后 3-5s）**：品牌 + 行动号召，转场 fadeblack 隔开，logo ≤2s

## 选镜头偏好

- 产品「被使用」的镜头 > 产品「被摆拍」的镜头
- 特写优先：质感、按键、反馈瞬间——广告的信任来自细节
- 人物出镜看镜头状态的「反应镜头」最值钱，留足时长
- 一刀只讲一个卖点；两个卖点挤一刀 = 两个都没讲到

## 声音

- music 选有明确鼓点的，刀落在鼓点上
- 旁白一句一个卖点，句尾对齐该卖点组最后一刀的出点
- sfx 给「产品发挥功能」的瞬间（快门/按键/开合），这是广告音效的本职

## 转场口径

默认硬切；卖点组之间可用 slide（并列感）；进 logo 用 fadeblack。禁用花哨转场——它们抢的是卖点的注意力。

## 常见坑

- 开头铺环境/铺氛围 3 秒才见产品——信息流里已经划走了
- 卖点罗列没有证据，可信度为零；证据堆太多，卖点又被稀释
- 收尾太长。观众已经决定要不要买了，别考验耐心

## 自查

- 只看前 3 秒，能说出这是什么产品吗
- 数卖点数：成片里的卖点组数和你想传达的一致吗（超过 3 个就砍）
- 最后一帧停的是品牌吗
