# 转场词表与声音层次

## 转场词表（全部可用转场，没有别的）

| type | 效果 | 什么时候用 |
|---|---|---|
| `cut`（默认） | 硬切 | 默认一切。硬切是剪辑的呼吸，不硬切才是需要理由的 |
| `fade` | 淡入淡出交叉 | 段落切换、时间流逝、抒情过渡 |
| `fadeblack` | 经黑场过渡 | 章节感更强的跳转、开场/收尾 |
| `dissolve` | 溶解 | 回忆/闪回、同主体时间推移 |
| `wipe` | 划像 | 明快的段落分隔，节奏快的片子 |
| `slide` | 滑入 | 并列内容切换（A 项到 B 项） |
| `zoom` | 缩放转场 | 冲刺感、进入新场景的推入 |
| `radial` | 旋转扫入 | 活泼/潮流向，慎用 |
| `none` | 同 cut | 显式声明这里故意不转场 |

## 使用纪律

1. **默认硬切**。特效转场是标点符号：句号（fadeblack）、分号（fade）、括号（slide），不是装饰。
2. 全片特效转场超过 30% 的刀数，基本可以断定在用转场掩盖镜头本身的弱——先改镜头。
3. 同类转场连续用会复读（review 会抓）；同类转场应该标记「同一种段落关系」。
4. duration 常用 0.3-0.6s；抒情段可到 1s；快档片 0.2-0.3s。
5. 转场落点对齐音乐转折——音乐换乐句而画面硬切 = 各自为政。

## 声音层次（三通道各司其职）

**music（铺底）**
- 有旁白必开 ducking（默认开）：旁白出现音乐自动让路，不需要手工配平
- fade_in/fade_out 各 1-2s，避免开头突兀、结尾戛然而止
- 音乐情绪跟段落走：换段落可以考虑换音乐（切两段音频挂不同起点），但别频繁

**narration（旁白/人声）**
- `at` 对齐对应画面：说到「这个设计」时画面就是这个设计——画面为先定刀，旁白跟着挪
- 长旁白切段挂点，段间留 0.2-0.5s 气口
- 旁白密度决定音乐音量：全程旁白 music 0.3 左右，空镜段可以到 0.6

**sfx（音效点缀）**
- 只在关键动作点：撞击、转场中点、标题出现、图钉钉下。一 laid 片 5-10 个足够
- `at` 落在动作帧，误差超过 0.2s 就露怯
- 音量 0.6-0.9，别盖过旁白

## 素材原声

时间线上的视频镜头原声**不进成片**。需要现场声/采访声：用 ffmpeg 提出来
（`ffmpeg -i 素材.mp4 -vn -acodec aac 原声.m4a`），放 assets/，挂 narration 通道对应时间点。
这也让「采访声压画面」这种经典手法变成两条决策：画面刀 + 声音挂点，各自独立调。
