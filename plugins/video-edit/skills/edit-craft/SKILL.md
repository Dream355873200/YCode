# Edit Craft：把素材剪成片

剪辑的本质不是拼长度，是**做决定**：哪几秒留下、为什么是它、下一刀落在哪里。
这个技能给你一套做决定的框架；具体字段格式见 `references/edl-format.md`。

## 什么时候用

- 用户给了若干段素材（拍的视频、图片、生成的镜头），要一条成片
- 长素材要切出精华（活动回顾、vlog 精华、访谈金句）
- 已有素材需要重排节奏、配乐、字幕

纯代码生成的动画/特效视频不走这里，走视频工坊。

## 工作流

### 1. 摸底素材（不摸底不排刀）

每个素材 `probe_media` 拿时长/分辨率/音轨。内容不明的先分析：
可以用视频工坊的 analyze_video 做场景切分和关键帧，或者自己抽帧看。
产出一张素材清单：**哪段素材里有什么、哪几秒可用、情绪是什么**。

素材分辨率混杂不用慌：时间线会统一规格化（cover 裁切铺满，改 `fit` 可换 contain 加黑边）。

### 2. 认片种，定节奏网格（先定档位再排刀）

先判断这是哪种片子，读对应的手册（都在 `references/genres/`，按需加载）：

| 片种 | 手册 | 一句话特征 |
|---|---|---|
| 广告 | `genres/ad.md` | 卖点+转化，15-60s，前 3 秒见产品 |
| 混剪快档 | `genres/montage.md` | 素材驱动、卡点、炸开场，音乐就是剪辑表 |
| 知识讲解 | `genres/explainer.md` | 旁白是骨架，画面对齐语义，一个知识点 2-5 刀 |
| 情绪叙事 | `genres/narrative.md` | 慢是能力，情绪曲线优先，环境声是第二条命 |

片种手册给的是这个片种的档位、结构模板、选镜头偏好和坑，优先级高于本文件的通用建议。
混合型片子（如带叙事感的广告）按主目标选手册，借另一本的局部技巧。

通用节奏网格参考 `references/pacing.md`：广告/混剪快档 40-70 刀/分钟，讲解/纪录片中档 15-30，叙事/氛围慢档 6-12。
先把总时长按段落分掉（钩子/主体/收尾），再决定每段几个镜头——**从结构推镜头数，不是拿到什么剪什么**。

### 3. 排刀（每刀必须有理由）

写 `edl.json`。每条 cut 的 reason 一句话讲清它为什么存在：
「金属反光特写承接上一刀的转速感」「笑声留到拍点，给观众反应时间」。
**说不清理由的镜头，再好看也删。**

声音和画面一起排：音乐段落转折落在哪一刀、旁白哪句配哪段画面、哪几个动作点要音效，见 `references/transitions.md` 的声音节。

### 4. 校验 → 小样 → 自看

check_edl 全绿 → render_cut(draft) → **自己看一遍小样**。看什么：
- 前 3 秒有没有钩子（观众划走就在这里）
- 最强的一刀有没有被平庸镜头稀释（保护强镜头）
- 节奏有没有中路垮掉（2 分钟谷，短片则是中段疲劳点）

### 5. 评分关

cut_review 六维评分。revise/fail 按给出的优先级改，acceptable 以上才出 final。
最后 render_cut(final)，随片汇报：结构思路一句话 + 重点段落在几秒 + 你做了哪些取舍。

## 判断题速查

| 情况 | 处理 |
|---|---|
| 素材够但都平庸 | 少而精，宁短勿水；快节奏救不了无聊的内容 |
| 素材里有一段极强的 | 围绕它排：前面铺垫、后面收束，别让插入镜头盖住它 |
| 用户没给音乐 | 先问；不问就按无声排，交付时说明可加 |
| 两个镜头跳 | 中间插反应/细节镜头，或用转场明确「跳是有意的」 |
| 镜头全差不多长 | 刻意做长短对比：长镜头蓄力，快切释放 |

## 红线

- 素材原声默认不进成片；要用先提出来挂音频通道
- 每次渲染后必过终审（工具自动做），终审不过不交付
- 不要为了凑时长放大段无用素材——观众感知的是密度，不是长度
