# 长视频工作流（3 分钟以上）

长片不是"更长的短片"。任何模型一口气生成 10 分钟都会风格漂移、节奏塌陷——
**正确做法是拆成多个短片 + 机制化保一致**。每个章节就是一个短片，走现有全部
流程（风格 → 场景 → check → inspect_frames）；长片特有的东西只有两样：
章节大纲（总案）和留存节奏设计。

## 工作流

### 1. 总案（一次成型，质量优先）

先写 `storyboard.md` 为章节大纲，模板（时长按需缩放，12 分钟示例）：

```
[开场钩子]   0:00-0:30   视觉钩子(最强画面) → 口头钩子(承诺/提问) → 利益点 → 预告 + 埋一个开放式悬念
[章节 1]     0:30-3:00   基础概念（必须在 2:00 前交付第一个实质性回报）
[小钩子]     3:00-3:15   给下一章留悬念（一句转场话 + 15 秒视觉切换）
[章节 2]     3:15-6:00   深入层
[换气段]     6:00-6:15   视觉呼吸/幽默/数据定格（palette cleanser）
[章节 3]     6:15-9:00   关键洞察 / aha 时刻
[实证]       9:00-10:30  案例 / 演示 / 数据
[结论]       10:30-11:30 回扣开场悬念 + 收束
[尾声]       11:30-12:00 CTA / 预告（不说"再见"）
```

硬规则：**10-15 分钟最多 5-6 章**（多了碎）；每章 2-4 分钟（简单概念 2-3、复杂 3-4、
实证 2-3）；**第一钩子 30 秒内完成**；**2:00 前交付第一个大回报**（这是留存谷的通行证）。

### 2. 章节生产（每章一个短片）

每章独立走完整流程，每章的上下文必须自包含：**全局风格圣经 + 本章规格 + 共享
组件清单**，绝不依赖"前面章节怎么做的"。一致性靠机制不靠记忆：

- 配色/字体锁定在 manifest 的 theme 对象，全片一份；
- 同类信息用同一组件（章节标题卡、要点列表、图表、对比卡各一个组件，全片复用只换内容）；
- 每章交付跑 `inspect_frames`（本章均匀帧 + 与片头风格卡对照），不过不进下一章。

章节内节奏随相位变化（留存数据支撑的经验值）：

| 相位 | 切换频率 | 说明 |
|---|---|---|
| 开场 0-30s | 每 3-5 秒 | 快切换传递能量 |
| 前段 | 每 10-15 秒 | 高能量，素材丰富 |
| 中后段 | 每 15-25 秒 | 稳定，穿插爆发段 |
| 每 2-3 分钟 | 一次 5-10 个快切的 10-15 秒爆发段 | 打断留存谷 |

"**必须有事发生**"规则：每 3-5 秒一次视觉/听觉变化，每 20-30 秒一次实质画面变化，
任何 15 秒的完全静止都会掉留存。re-hook 句式在每章开头给"继续看的理由"
（"但这还不是最有意思的部分…"）。大变化（风格切换/音乐能量变化）每 60-90 秒一次。

### 3. 解说与文案

- 中文解说 **220-260 字/分钟**（约 4-4.5 字/秒）；钩子段更快、关键洞察放慢、
  重大结论后留 1-3 秒静默让它落地。
- 文案按章节写进 storyboard，**先稿后画**：画面切点从稿子的节拍来，不是反过来。

### 4. 配乐（整条生成，不要分段拼）

`video-audio` 技能 + mgaudio 一次生成整条：`duration=全片时长`，
`energy=[(t,0..1),…]` 按章节标强度（钩子高、中段稳、谷位抬、结论起）、
`drop`=第一个大回报点。母带统一 -14 LUFS——**章节间响度差 < 2 LUFS**，
渲染后用 ffprobe 抽查每章响度。有解说的段落音乐靠 manifest 的 `duck` 闪避。

### 5. 拼装与整片验收

- 全部章节进同一 manifest（scenes 按序），章节标题卡组件统一；
- 整片渲染后 `inspect_frames` 整片均匀 12-16 帧 + 每章各补 2 帧：核对风格一致性
  （像不像同一部片）、章节转场、字幕连续性；
- 交付说明里附章节时间戳（0:00 引言 / 0:30 …），平台章节导航用。

## 模型策略（强弱搭配）

- **总案、风格设计、难场景、整片评审**：用强模型（这是质量上限所在）；
- **章节填空**：把章节规格写死成"填空题"（标题/要点/数据/图表类型），弱模型也能达标；
- 每章独立轮次/子任务，串行推进，上一章验收过了才开下一章。

## 常见失败模式

- 一口气生成 → 后半风格漂移、组件乱用。**每章必须重读风格圣经的「本质/不是什么」**。
- 只顾信息密度不留呼吸 → 2 分钟谷崩塌。回报点、爆发段、换气段是结构性的，不是装饰。
- 每章响度不一致 → 观感"拼接感"。整条配乐 + 抽查解决。
- 开场 30 秒还在铺背景 → 大部分观众已经走了。钩子里必须有承诺和悬念，铺垫进第一章。
