# 实现指南：STYLE.md → Remotion 工程

按风格的实现族落到不同技术路径；同一风格内所有场景共享同一套实现决策。

## 实现族映射

| 风格族 | 技术路径 | 代表风格 |
|---|---|---|
| 矢量/排版/几何 | React + kit 组件 + 自绘 SVG/CSS | 装饰艺术、瑞士排版、包豪斯几何、蓝图、极简键线 |
| 手绘/颗粒/物理材质 | `<canvas>` 逐帧程序化绘制（`useCurrentFrame` 驱动，确定性） | 油画厚涂、水彩、risograph、蜡笔、逐帧沸腾 |
| 图像后处理风格 | 底图 + 滤镜链（chromatic aberration/grain/VHS 用 CSS/Shader） | 合成波、复古半调、暗色科技 |
| 3D | kit 的 ThreeStage / @react-three/fiber | 低多边形、白模投影、软胶 3D |
| 混合 | 分层：canvas 质感层 + DOM 排版层 + 前景层 | 全息 HUD、卡通动画类 |

## 逐节落地法（STYLE.md 的每一节都是实现输入）

1. **材质与渲染节** → 决定技术路径和绘制方式；里面的数值（描边宽、透明度层级、
   模糊半径）直接抄成常量，不要"感觉差不多"。
2. **色彩逻辑节** → 写成 theme.palette（基色/强调色/留白色），**强调色的使用约束
   （"只用于锁定值"这类）写成注释放在 palette 旁**，全片只有一处消费点。
3. **字体节** → 优先用运行时已装字体的最接近气质；落选时在交付说明里讲清楚。
   字号/字重/字距/行高的数值照抄，排版规则（全大写、宽字距）用代码保证。
4. **动效质量节** → 提炼成项目的 easing 常量与入场时序（overshoot 百分比、错峰帧数），
   全片共享一个 motion.ts，禁止场景里各写各的缓动。
5. **镜头语法节** → 场景切换与相机行为按它来；"镜头从不旋转"这类否定规则要写进 check 注释。
6. **引擎节** → 作者已给出 Remotion 实现建议的，按建议做。

## 确定性渲染纪律（手绘/颗粒/噪声类重灾区）

- 噪声/颗粒用 `@remotion/noise`（以帧号/种子为输入），**禁止 Math.random**；
- "沸腾/手抖"类效果用种子步进：`seed = floor(frame / 每几帧)` 取离散变体，
  不要用连续噪声——连续抖动读起来是 VHS，不是手绘；
- 所有随机排布（星点、纸纹斑点）种子化，重渲必须逐帧一致。

## 常见跑偏（按风格族）

- 矢量族：加了渐变/阴影破坏扁平契约；缓动弹性不足像 PPT。
- 手绘族：噪声连续化（抖成 VHS）；纹理忘了跟随相机。
- 3D 族：光源不统一（多场景各开各的灯）；DOF 滥用。
- 排版族：字距/网格不严格——排版风格里排版就是骨头，差 2px 都看得出来。
